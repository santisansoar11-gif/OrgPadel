# Padel Tournament Organizer — TP8

Proyecto PHP/MySQL de organización de torneos de pádel.

**Guía de instalación y demostración:** [`tp8/README_TP8.md`](tp8/README_TP8.md).

- Conserva el CRUD de torneos desarrollado en TP7.
- Agrega autenticación con bcrypt, login/logout, sesión y protección de roles.
- No necesita recrear ni modificar la base de datos de TP6.
- Conserva `tp7/README_TP7_ANTERIOR.md` como documentación histórica.

Para uso local: iniciá Apache y MySQL, abrí `http://localhost/Padel_Tournament_Organizer_TP8/` y probá `/registro.php`, `/login.php` y `/mi-cuenta.php`.

Los scripts y archivos de configuración no son navegables públicamente (reglas `.htaccess` para Apache 2.4).
